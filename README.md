# MA3 Hub by Bendt Van Hoey

Connects grandMA3 and grandMA2 consoles with MIDI controllers, Ableton Link and more.

## Download

- **Mac** (Apple Silicon): [MA3Hub-mac.dmg](https://github.com/Bendtvh/MA3Hub-Releases/releases/latest/download/MA3Hub-mac.dmg)
  Open it and drag MA3 Hub into Applications.
- **Windows**: [MA3Hub-Setup-Windows.exe](https://github.com/Bendtvh/MA3Hub-Releases/releases/latest/download/MA3Hub-Setup-Windows.exe)

After installing, MA3 Hub keeps itself up to date.
